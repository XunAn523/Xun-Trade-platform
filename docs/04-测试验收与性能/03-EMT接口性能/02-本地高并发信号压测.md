# 本地网关链路与高并发信号压测

`gateway-local-signal-burst` 使用真实 `OrderGateway`、`FileJournal` 与无副作用 native port；它不会加载 EMT SDK、登录、联网或产生订单。它是本地性能验收门槛，不可替代 EMT/柜台时延测试。

## 1 Hz 本地硬门槛

目标是在均匀一条信号/秒时，每个本地链路的 p99 不超过 1 ms：

| 纳入 1 ms 门槛 | 含义 |
| --- | --- |
| C0→C1 | 网关准入 |
| C1→C2 | `CALL_STARTED` 耐久化 |
| C2→C3 | native 调用交接 |
| C3→C4 | native SDK 方法返回 |
| C5→C6 | 回调出 ring 后的事件耐久化 |
| C6→C7 | 本地投递 ACK |

`C4→C5` 被明确排除：它是 native 返回到首个 EMT 回调到达的等待，包含 EMT SDK、网络和柜台处理时间，不能作为本地网关承诺。

优化后的实现包括：空闲低频时直接耐久化，竞争时受限组提交；回调消费者由事件唤醒，且在 ring 为空时不为假想的下一条回调等待合批窗口；短组提交截止使用 Linux 单调时钟 `perf_counter_ns()`，避免低精度定时等待。

执行 30 条的本地 1 Hz 门槛验证：

```bash
.venv/bin/python -m tools.performance.perfbench.cli --driver gateway-local-signal-burst --signal-rate 1 --signal-rounds 30 --signal-arrival uniform --signal-journal-mode group-commit --signal-group-wait-ms 0.1 --signal-group-size 128 --signal-callback-batch-size 64 --signal-callback-collect-wait-ms 0 --output ./artifacts/performance/local-signal-1hz-30-local-gate.json
```

本机最新结果中，C0→C1 p99 为 0.036 ms、C2→C3 为 0.005 ms、C3→C4 为 0.006 ms、C5→C6 为 0.944 ms、C6→C7 为 0.061 ms；但 C1→C2 为 **2.344 ms**。这条路径包含 NTFS `fsync`，其尾延时超出 1 ms，故 `one_signal_per_second_local_gate.passed=false`。

不得为达标而移除“命令耐久化后才越过 native 调用边界”的保护。当前硬件/NTFS 刷盘尾延时未满足该性能门槛；任何显式绕过后的 EMT 仿真测试只能证明接口语义，不能证明本地 1 ms p99。

## 300 QPS 高并发验证

300 QPS 是一个一秒窗口内均匀投递 300 条信号；这不同于 300 条在同一时刻到达的突发排队测试。当前受限组提交配置为最多 128 条、最多 0.1 ms；低频一条/秒才启用空闲直写。

```bash
.venv/bin/python -m tools.performance.perfbench.cli --driver gateway-local-signal-burst --signal-rate 300 --signal-rounds 10 --signal-arrival uniform --signal-journal-mode group-commit --signal-group-wait-ms 0.1 --signal-group-size 128 --signal-callback-batch-size 64 --signal-callback-collect-wait-ms 0 --output ./artifacts/performance/local-signal-300-uniform-current.json
```

本机结果：3000/3000 成功，299.63/s，无回调溢出；C0→C4 p99 2.040 ms，C5→C7 p99 1.659 ms。该结果说明高并发路径无丢失，但不能覆盖 1 Hz 的 1 ms 耐久化门槛失败。

## 受控 EMT 委托前置条件

`gateway-controlled-order` 默认在加载 SDK、登录或发单之前要求传入一个通过的 `--local-latency-gate-report`。报告必须来自本驱动、账号无关、均匀 1 Hz，且 `one_signal_per_second_local_gate.passed=true`。

仅对已授权的 EMT 仿真接口验证，可同时提供 `--skip-local-latency-gate` 和 `--execute-simulated-mutations` 跳过该性能门槛。报告会记录 `local_one_hz_gate.mode=explicitly_bypassed`，此类结果不得作为 1 Hz 低尾延时或生产准入证据。
