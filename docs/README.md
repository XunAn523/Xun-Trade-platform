```text
└─ 05-项目汇报与图表/         汇报稿、Mermaid 源图与可复用图片
```

## 权威性与维护规则

1. EMT 官方 SDK、券商下发的 SDK 包、账户权限与运行时 capability report 高于设计文字；发现差异时先停止相关能力，再更新矩阵和验收记录。
2. 架构和副作用不变量以 `01-架构与定档` 为准；字段、错误码和数据模型以 `02-接口与数据` 为准；部署、发布与运行处置以 `03-部署运维与可观测性` 为准；性能结论必须以 `04-测试验收与性能` 的原始测量和门禁为准。
3. 协议字段只能新增 optional 字段；涉及副作用、权限、恢复、持久化、可观测性或告警的变更，必须同步更新设计、测试和运维文档。
4. 当前运行基线为 Linux x86_64 与独立 `.venv` 中的 CPython 3.10。Windows 记录仅作历史审计，不能替代 Linux 兼容性或性能验收。
